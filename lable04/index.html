我是陈堯，广州软件学院软件工程专业在读学生。 我的学习与项目主要围绕 AI 辅助开发、大语言模型应用和前后端开发展开。

在技术方面，我使用 Python、Java 和 TypeScript 进行主要开发，接触过微信小程序、Spring Boot、 FastAPI、MySQL、Vue、ECharts、Canvas 和 SVG。在 AI 方向，我持续学习 RAG、向量检索、 大语言模型 API 调用与 AI 应用构建。我更关注技术如何解决真实问题， 并逐渐形成从需求拆解、界面设计、接口实现到部署测试的完整开发意识。

技能结构

  • 编程语言 — Python · Java · TypeScript · HTML / CSS
  • 前端与小程序 — 微信小程序 · Vue · 响应式布局 · ECharts · Canvas · SVG
  • 后端与数据 — Spring Boot · FastAPI · MySQL · 微信云开发
  • AI 与大语言模型 — RAG · 向量检索 · 大语言模型 API · Streamlit · 知识索引与引用出处
  • 工具与协作 — Git / GitHub · 需求梳理 · 界面设计 · 项目文档 · 测试与迭代

做事方式 & 目标

  • 先明确使用场景，再拆解功能、确定技术方案，最后通过迭代完善

  • 重视落地：项目大多来自具体场景，而不是纯练习
  • 短期：完善 AI 应用项目，提升工程化能力与代码质量

  • 长期：成为能够独立构建 AI 应用的软件工程师
